# 简支梁力学分析系统

当前完成第一阶段：跨中集中力作用下简支梁的支座反力、剪力、弯矩和理论挠度计算。

## 安装与测试

在项目根目录执行：

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pytest -v
streamlit run app.py

## 单位

所有输入必须统一使用：

- 长度 `L`：mm
- 集中力 `P`：N
- 弹性模量 `E`：MPa，即 N/mm²
- 截面惯性矩 `I`：mm⁴

不要混用 m、kN 等单位；函数会拒绝非数值、无穷大、零或负数等非法输入。

## 当前模型的适用条件

仅适用于跨中集中力、两端理想简支、均匀等截面梁、材料线弹性且小挠度的情况。当前不考虑剪切变形、塑性、自重、动态荷载、任意位置集中力和均布荷载。

## 验算示例

给定 `L=1000 mm`、`P=100 N`、`E=200000 MPa`、`I=1000000 mm⁴`：

- 左右支座反力：`50 N`
- 最大剪力绝对值：`50 N`
- 最大弯矩：`25000 N·mm`
- 最大挠度位置：跨中 `500 mm`
- 跨中挠度：`-0.0104167 mm`（负号表示向下）
