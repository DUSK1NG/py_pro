# 项目报告提纲（5～10 页）

## 1. 项目背景与目标

说明简支梁挠度测量的工程意义、理论计算目标和计算机视觉目标。

## 2. 理论模型

介绍简支梁边界条件、三类荷载、支座反力、剪力、弯矩和挠度公式，以及统一单位制。

## 3. 软件设计

介绍 mechanics、vision、visualization、utils 和 Streamlit 界面之间的数据流。

## 4. 图像识别方法

说明高对比度标记点、灰度化、滤波、阈值分割、形态学处理、轮廓筛选和像素标定。

## 5. 实验装置与步骤

插入实验装置照片、梁参数、荷载方案、拍照设备位置和标定物设置，并说明上传的未加载图片与加载图片。

## 6. 结果与误差分析

插入理论挠度曲线、实测挠度曲线、理论/实测对比图、CSV 数据和误差指标。

## 7. 问题与改进

讨论透视误差、光照变化、标记点识别失败和支座非理想等问题。

## 8. 结论

总结系统完成情况、实验结果可信度和静态图片测量方案的适用范围。
