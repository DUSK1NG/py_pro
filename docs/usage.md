# 使用说明

应用有“基础理论分析”和“教材题求解器”两种模式。基础分析支持跨中集中力、任意位置集中力和满跨均布荷载；教材题模式可输入多个支座、集中力和区间均布荷载。两种模式都显示反力、剪力、弯矩和挠度结果，并提供图表与报告导出。

## 教材题输入

输入梁长 `L`、弹性模量 `E`、截面惯性矩 `I`，再填写支座、集中力和均布荷载表。输入使用内部单位：长度 `mm`、力 `N`、均布荷载 `N/mm`、弹性模量 `MPa`、惯性矩 `mm⁴`。集中力和均布荷载可带正负号；向上为正，向下为负，向下挠度为负。

支座类型如下：

- `pin`（铰支）：限制竖向位移；
- `roller`（滚支）：限制竖向位移；
- `fixed`（固定）：限制竖向位移和转角，并产生竖向反力与反力矩；
- `free`（自由）：不施加约束。

此模型只计算竖向弯曲，不计算水平反力。程序检查梁长、`E` 和 `I` 为正数，支座及荷载位置在梁长范围内，且支座位置不重复、均布荷载起点小于终点。约束不足而形成机构的输入会报错。

左端铰支、右端滚支的简支梁，以及梁端固定、其余支座为自由的悬臂梁使用解析解。其他有效支座组合使用梁有限元数值解；解析与数值解都会给出平衡检查和适用提示。

## 截面惯性矩

基础理论模式提供矩形、实心圆形和自定义截面。矩形宽度 `b`、高度 `h` 和圆形直径 `d` 均以 mm 输入：

- 矩形：`I = b h³ / 12`；
- 实心圆：`I = π d⁴ / 64`；
- 自定义：直接输入以 `mm⁴` 为单位的 `I`。

## 模型假设

计算采用均匀等截面 Euler–Bernoulli 梁模型，只考虑竖向荷载与弯曲；不计算轴向变形、扭转、剪切变形或大挠度效应。

## 结果与报告

结果区显示最大剪力、最大弯矩和最大挠度及其位置，并提供剪力图、弯矩图和挠度曲线。完成计算后可下载图表数据或 Markdown、PDF 报告；教材题报告包含输入、反力、平衡检查和求解步骤。

## 验算示例

简支梁取 `L=1000 mm`、跨中向下集中力 `P=100 N`、`E=200000 MPa`、`I=1000000 mm⁴`：左右支座反力均为 `50 N`，最大剪力绝对值为 `50 N`，最大弯矩为 `25000 N·mm`（跨中），跨中挠度为 `-0.0104167 mm`。
