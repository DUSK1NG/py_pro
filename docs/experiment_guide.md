# 简支梁挠度监测实验说明

## 一、低成本装置

- 梁：木条、亚克力条或薄金属条；
- 支座：两个高度一致的硬质支撑物，一端允许转动，另一端允许少量水平滑动；
- 荷载：已知质量砝码或装水容器；
- 拍照设备：手机或相机，用于获取两张静态图片；
- 背景：与梁和标记点形成明显明暗对比的纯色背景；
- 标定物：与梁处于同一平面的直尺、标定杆或已知长度标记。

## 二、安装和拍摄

1. 测量两支座之间的有效梁长，并记录单位为 mm。
2. 保证两个支座顶面高度一致，梁两端不要被夹紧。
3. 在梁跨中粘贴一个圆形高对比度标记点。
4. 将拍照设备固定在三脚架或支架上，使镜头尽量正对梁的侧面。
5. 标定物放在与梁标记点相同的平面，避免前后景深差造成比例误差。
6. 保持焦距、摄像头位置和光照不变，先拍摄未加载基准图。
7. 按计划荷载加载，等待梁静止后拍摄加载图。

## 三、标定和识别

第一版程序要求人工输入标定物实际长度和对应像素长度。程序使用：

```text
mm_per_pixel = 实际长度（mm） / 像素长度（pixel）
```

建议使用浅色圆点配深色背景，或者深色圆点配浅色背景，并在界面中选择对应目标颜色和阈值。

## 四、重复实验和误差控制

- 每个荷载水平至少重复拍摄 3 次；
- 每次加载前确认梁没有残余变形；
- 每次卸载后检查标记点是否回到基准位置；
- 不要让荷载超过梁的弹性范围；
- 记录温度、光照变化、荷载位置和拍摄时间；
- 若识别失败，优先检查背景对比度、阈值、ROI 和拍照设备是否移动。

## 五、误差来源

- 像素标定长度读取误差；
- 拍照设备轻微移动；
- 透视和镜头畸变；
- 标记点粘贴位置偏差；
- 荷载值或荷载位置误差；
- 梁支座摩擦和边界条件不理想。

当前版本不自动进行透视校正，实验时应尽量使镜头光轴垂直于梁的侧面。
