# 静态图片跨中挠度测量设计

## 目标

为简支梁分析系统增加一个适合实验室第一版的计算机视觉模块：读取未加载图片和加载后图片，识别梁跨中处的高对比度标记点，计算像素位移，并依据标定长度换算为实际挠度。

本阶段只测量跨中一点，不处理视频、不自动提取整条梁中心线，也不引入深度学习。

## 选择的识别方案

实验时在梁跨中粘贴颜色或灰度明显不同于背景的圆形标记。程序对两张图片执行相同的处理流程：灰度化、轻度高斯滤波、二值化、形态学去噪、轮廓提取，并从候选轮廓中选择面积和形状满足条件的标记点。

相比直接识别梁边缘，该方案对梁颜色、背景纹理和轻微边缘缺失更不敏感；相比特征点匹配，实现简单、可解释，便于学生在实验中调整阈值。

## 模块接口

新增 `vision/static_deflection.py`，保持纯函数和 NumPy/OpenCV 数组接口：

- `detect_marker_center(image, threshold=..., min_area=..., max_area=...) -> tuple[float, float]`
  - 输入 BGR 或灰度图片。
  - 返回标记点中心 `(x_pixel, y_pixel)`。
  - 找不到唯一有效标记点时抛出 `ValueError`。
- `measure_midspan_deflection(reference_image, loaded_image, calibration_length_mm, calibration_pixels, ...) -> dict`
  - 检测两张图片中的标记点。
  - 计算 `pixel_displacement`、`deflection_mm`、`reference_center`、`loaded_center`。
  - 图像坐标 y 向下为正；加载后标记点向下移动时，输出挠度取负值，与理论挠度约定一致。
- `calibrate_mm_per_pixel(length_mm, pixel_length) -> float`
  - 返回 `length_mm / pixel_length`。
  - 拒绝非有限数值、非正实际长度和非正像素长度。

返回字典保留基础数值，便于后续 Streamlit、CSV 导出和理论/实测曲线对比模块复用。

## 数据流

```text
未加载图片 ─┐
            ├─> 标记点检测 ─> 两中心坐标 ─> 像素位移 ─> mm/像素标定 ─> 跨中实测挠度
加载后图片 ─┘
```

标定物可以是直尺、标定杆或图中两点之间的已知距离。第一版由用户提供实际长度（mm）和对应像素长度，不自动识别标定物。

## 异常处理

- 图片为空、维度不支持或无法转换为灰度图：抛出 `ValueError`。
- 没有候选轮廓：抛出“未检测到标记点”。
- 候选轮廓不唯一且无法依据面积/圆度选出明显最佳候选：抛出“标记点不唯一”。
- 标定输入不合法：抛出明确的中文 `ValueError`。
- 两张图未检测到标记点时，不返回部分结果，避免把错误识别当成零挠度。

## 测试设计

新增 `tests/test_static_deflection.py`，使用 NumPy 生成黑色背景上的白色圆形标记，不依赖真实照片：

1. 检测单个圆形标记的中心坐标，允许小于 1 像素的误差。
2. 参考图和加载图标记点发生已知像素下移时，验证像素位移和毫米挠度换算。
3. 验证标定换算结果及零/负数输入拒绝。
4. 验证空图、没有标记点和多个同等候选轮廓会抛出 `ValueError`。

测试先写并确认失败，再实现最小识别流程，最后运行完整测试集。

## 暂不包含

- 视频流和实时摄像头；
- 整条梁挠度曲线；
- 自动识别标定尺；
- 自动调用 Streamlit 上传控件；
- 理论值与实测值的误差报告。

这些功能在跨中单点识别稳定后再逐步增加。
