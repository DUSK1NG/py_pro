# 第一阶段设计：跨中集中力简支梁计算模块

## 目标与范围

实现水平、两端简支、均匀等截面梁在跨中受到竖向集中力时的理论计算。第一阶段只交付可复用的 Python 计算函数和自动化测试；不包含绘图、界面、截面惯性矩计算、任意位置集中力、均布荷载或 OpenCV 功能。

## 单位与适用条件

所有输入必须采用：长度 `L` 为 mm、力 `P` 为 N、弹性模量 `E` 为 MPa（N/mm²）、截面惯性矩 `I` 为 mm⁴。因此弯矩单位为 N·mm、挠度单位为 mm。

模型适用于线弹性、小挠度 Euler–Bernoulli 梁：材料均匀、截面恒定、两端为理想铰支与滚动支座；忽略剪切变形、自重、塑性和动态效应。

## 模块边界

`utils/validation.py` 负责确认输入为有限实数，且 `L`、`P`、`E`、`I` 均大于零；采样点数量为不小于 3 的整数。

`mechanics/central_point_load.py` 只负责力学计算，提供：

- 支座反力 `RA`、`RB`；
- 指定位置的剪力 `V(x)`；
- 指定位置的弯矩 `M(x)`；
- 指定位置的挠度 `v(x)`；
- 等间距采样得到的计算结果，包含最大剪力、最大弯矩、最大挠度及其位置。

公共接口避免依赖绘图库，以便后续阶段直接复用到绘图和 Streamlit。

## 计算约定与公式

取横坐标 `x` 自左支座向右，范围为 `[0, L]`。向上的支座反力为正，左截面向上的剪力为正，正弯矩为下挠（受拉在梁底）的弯矩。挠度取向上为正，因此向下挠度为负。

支座反力：

`RA = RB = P / 2`

剪力（跨中剪力不连续；函数约定在 `x = L/2` 返回左极限）：

`V(x) = P/2`，当 `0 <= x <= L/2`；

`V(x) = -P/2`，当 `L/2 < x <= L`。

弯矩：

`M(x) = P*x/2`，当 `0 <= x <= L/2`；

`M(x) = P*(L-x)/2`，当 `L/2 < x <= L`。

挠度：

`v(x) = -P*x*(3*L^2 - 4*x^2)/(48*E*I)`，当 `0 <= x <= L/2`；

`v(x) = -P*(L-x)*(3*L^2 - 4*(L-x)^2)/(48*E*I)`，当 `L/2 < x <= L`。

因此：`M_max = P*L/4`，位置为 `L/2`；`v_max = -P*L^3/(48*E*I)`，位置为 `L/2`。报告最大挠度时同时提供带符号值和绝对值，以避免符号含义被误解。

## 错误处理

输入缺失、非数字、NaN、无穷大、非正参数、非整数采样点以及梁外位置 `x` 必须抛出带中文说明的 `ValueError`。模块不接受 kN、m 等混合单位；调用方需在传入前换算为约定单位。

## 测试与验收

使用 `pytest` 编写测试，并遵循测试先行。

1. 对 `L=1000 mm`、`P=100 N`、`E=200000 MPa`、`I=1000000 mm^4` 验证 `RA=RB=50 N`。
2. 验证剪力在跨中两侧分别为 `+50 N` 与 `-50 N`。
3. 验证跨中弯矩为 `25000 N·mm`，两端弯矩为零。
4. 验证跨中挠度符合 `-P*L^3/(48*E*I)`，两端挠度为零。
5. 验证挠度关于跨中对称，采样结果的最大弯矩和最大绝对挠度出现在跨中。
6. 验证非法参数和梁外位置被拒绝。

验收标准：所有测试通过；核心函数均含中文文档字符串和必要注释；无 OpenCV、绘图或界面代码。
