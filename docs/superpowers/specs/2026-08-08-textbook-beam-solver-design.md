# 简支梁教材题求解器设计说明

状态：待审核
日期：2026-08-08

## 1. 目标与边界

本功能面向材料力学教材习题，允许用户直接输入梁长、材料/截面参数、多个集中力、多个部分均布载荷以及不同位置的竖向约束，输出可复核的受力分析结果。首版采用“解析解优先、有限元兜底”的路线：能识别为标准静定题时给出公式和解题步骤；一般约束或超静定题使用一维 Euler–Bernoulli 梁有限元计算，并明确标注为数值解。

本功能只处理平面内竖向弯曲，不计算轴向位移、水平反力、扭转、剪切变形和大挠度效应。界面会显示该假设，避免把横向模型误解为完整二维刚体支座模型。暂不加入集中力矩、非均匀分布载荷、视频/实时摄像头和自动透视校正。

## 2. 用户输入模型

### 2.1 梁与单位

- 梁长 `L`，内部统一换算为 mm。
- 弹性模量 `E`，内部统一换算为 MPa。
- 截面惯性矩 `I`，内部统一换算为 mm⁴；可继续使用已有矩形、圆形、工字形等截面计算入口。
- 用户输入可沿用现有 KN/N、m/mm、GPa/MPa 等下拉单位，计算前完成换算。

### 2.2 约束列表

每行包含：位置 `x`、约束类型、备注（可选）。位置范围为 `0 ≤ x ≤ L`，同一位置不能重复定义约束。

- `固定端`：约束竖向位移 `v=0` 和转角 `θ=0`。
- `铰支座`：约束竖向位移 `v=0`，允许转角。
- `滚动支座`：在本竖向弯曲模型中同样约束 `v=0`、允许转角；与铰支座的水平反力差异不在本模型内计算。
- `自由端`：不产生约束，主要用于明确梁端边界；不作为反力未知量。

首版预置“简支梁（左铰右滚）”和“悬臂梁（左固定右自由）”快捷模板，用户仍可编辑位置和类型。任意内部支座、多个固定端或不对称约束均可输入，但通常会切换到有限元数值解。

### 2.3 荷载列表

使用两个可动态增删行的表格：

1. 集中力：位置 `x`、大小 `P`、方向（向上/向下）。位置必须落在梁段内或节点上，允许作用在支座位置。
2. 部分均布载荷：起点 `x1`、终点 `x2`、强度 `q`、方向（向上/向下）。要求 `0 ≤ x1 < x2 ≤ L`。

输入的方向转为带符号的竖向力；输出约定为向上为正、向下为负，挠度向下为负，以保持与当前理论结果和图表一致。

## 3. 求解策略

### 3.1 静定解析分支

识别以下标准边界：

- 两个竖向位移约束、无转角约束的左铰右滚简支梁；
- 一个固定端、其余为自由端的悬臂梁。

对识别出的题型，先由整体平衡方程求支座反力，再按荷载和支座位置分段生成剪力 `V(x)`、弯矩 `M(x)`，并采用现有解析挠度框架或叠加公式求 `v(x)`。分段断点至少包括支座、集中力位置、均布载荷起止点。输出同时保留用于绘图的离散采样数组。

解析结果必须包含：反力、每个区间的剪力/弯矩表达式、最大剪力、最大弯矩、最大挠度位置与数值，以及代入本题数据后的解题步骤。

### 3.2 一维梁有限元兜底分支

对未被解析分支识别的约束组合，使用二维节点自由度的 Euler–Bernoulli 梁单元：每个节点包含 `[v, θ]`，单元刚度采用 `EI/L_e³` 标准矩阵。

- 自动在所有支座、集中力位置和均布载荷边界建立节点，保证荷载不会落在单元内部而被近似错位。
- 其余区间按最大单元长度或最大单元数细分；默认控制总单元数不超过 200。
- 均布载荷使用一致节点荷载向量，集中力直接施加到对应节点。
- 施加位移/转角约束后求解 `K u = F`；反力由 `K u - F` 计算。
- 矩阵奇异时返回“机构或约束不足”的可读错误，不显示误导性的数值结果。
- 在报告中显示“有限元数值解”，并给出网格数量、节点数量和收敛/精度说明。

静定题可选执行一次有限元交叉校核；解析与有限元的最大反力、弯矩、挠度差异超过容差时提示复核输入或符号约定。

### 3.3 静定性分类

分类基于当前竖向弯曲模型：统计有效约束自由度与整体平衡可提供的独立方程，并结合刚度矩阵可解性判断“静定”“超静定（数值解）”或“机构/约束不足”。界面明确说明该分类不包含水平反力和三维支座自由度。

## 4. 解题步骤与结果展示

结果区按教材解题顺序排列：

1. **题目输入摘要**：梁长、材料、截面、支座与荷载表、单位。
2. **受力简图数据**：在现有图表风格中标出支座、荷载、坐标和方向。
3. **求解方法**：解析解/有限元数值解及静定性判断。
4. **支座反力**：逐个支座列出竖向反力；固定端额外列出反力矩。
5. **平衡校核**：`ΣFy`、`ΣM` 以及约束反力残差。
6. **剪力与弯矩**：分段表达式、关键断点表、最大值位置，并绘制图形。
7. **挠度**：理论曲线、最大挠度和位置；有限元分支显示节点结果。
8. **学习提示**：列出符号约定、边界条件、适用假设和需要人工复核的项目。

解析表达式以可读的数值系数呈现，避免依赖符号计算库；每个区间同时保留可执行的函数对象，供绘图、CSV 和报告复用。

## 5. Streamlit 交互设计

在现有 `app_styled.py` 中新增“教材题求解器”入口，不改变现有基础计算、图片测量和实验数据分析流程。

- 使用 `st.form` 批量提交梁参数、支座表和荷载表，避免每次编辑表格都触发求解。
- 用 `st.data_editor` 提供可增删的支座/集中力/均布载荷行，并在列配置中限制类型与方向选项。
- 提供“简支梁模板”“悬臂梁模板”“清空输入”三个快捷操作。
- 校验错误就地显示在对应输入区；错误时不覆盖上一次成功结果。
- 成功后显示方法徽标、反力卡片、图表、分段表和“解题步骤”折叠区。
- 导出入口沿用现有报告弹窗，新增教材题输入摘要、反力、分段剪力/弯矩、节点挠度和校核数据。

## 6. 数据接口与兼容性

新增独立的输入/结果数据结构，避免把教材题参数继续塞入现有 `calculate_beam` 的固定参数列表。建议接口如下：

```text
solve_textbook_beam(problem: BeamProblem) -> BeamSolution
classify_problem(problem: BeamProblem) -> ProblemClassification
solve_analytical(problem: BeamProblem) -> AnalyticalSolution
solve_fem(problem: BeamProblem, options: FEMOptions) -> FEMSolution
```

`BeamSolution` 至少包含 `method`、`classification`、`reactions`、`shear_segments`、`moment_segments`、`x`、`deflection`、`checks`、`steps` 和 `warnings`。现有单一荷载模块保持兼容，教材题求解器通过新模块调用已有单位换算和绘图/报告工具。

## 7. 验证与测试

按测试驱动方式先写失败测试，再实现：

- 输入校验：越界位置、重复支座、`x1 >= x2`、负长度、非法 `E/I`、空荷载表和自由机构。
- 解析基准：跨中集中力、全跨均布载荷、偏心集中力、部分均布载荷、悬臂端力与端矩（端矩暂不作为 UI 输入）。
- 叠加性：两个集中力、两个均布区间的结果等于单荷载结果叠加。
- 分段连续性：非荷载断点处剪力/弯矩连续；集中力处剪力跳跃量等于荷载；均布段弯矩二阶关系正确。
- 有限元校核：标准简支梁和悬臂梁网格加密后与解析解误差在容差内；奇异矩阵给出机构错误。
- 符号约定：向下荷载产生负挠度，反力和平衡残差满足预期。
- Streamlit：模块可导入、`app_styled.py` 可编译，现有全部测试保持通过。
- 报告/CSV：输入、解题步骤、反力、曲线和误差字段可被标准软件读取。

验收目标：现有 77 项测试继续通过；新增核心计算测试覆盖所有上述分支；标准解析题反力和最大挠度相对误差不超过 `1e-8`，有限元交叉校核默认不超过 `1e-3`（相对量，接近零处使用绝对容差）。

## 8. 分阶段交付

1. 数据结构、校验和模板；
2. 静定简支梁解析分支与教材步骤；
3. 悬臂梁解析分支；
4. Euler–Bernoulli FEM 与静定性/机构判断；
5. Streamlit 表格输入与结果区；
6. 报告、CSV、图表导出；
7. 回归测试、README 使用说明和示例题。

每一阶段都先补测试并运行全量测试，再进入下一阶段。真实实验图片识别仍属于既有静态图片模块，不与本教材题求解器混合验证。

## 9. 明确不做的事项

- 不自动从教材图片识别题目参数；
- 不把合成数据当作真实实验结论；
- 不实现视频或实时摄像头；
- 不在首版加入三维支座、轴力、扭矩、剪切变形和材料非线性；
- 不在未验证符号和边界条件前生成“标准答案”措辞，所有数值结果均附带假设和复核提示。
