# 第三阶段设计：任意位置集中力简支梁

## 目标与范围

支持集中力 `P` 在简支梁任意内部位置 `a` 的理论计算，输出支座反力、剪力、弯矩、挠度和可供现有绘图模块消费的采样结果。

荷载位置限制为 `0 < a < L`。保持统一单位：`L`、`a` 为 mm，`P` 为 N，`E` 为 MPa（N/mm²），`I` 为 mm⁴；挠度向下为负。

## 模块边界

新增 `mechanics/point_load.py`，不修改 `mechanics/central_point_load.py` 的公共接口。新模块提供与第一阶段对应的反力、剪力、弯矩、挠度和采样函数；其采样字典继续使用 `x`、`shear`、`moment`、`deflection` 键，因此 `visualization.plotting` 无需改动。

## 理论公式

设 `b = L - a`。

- 支座反力：`RA = P*b/L`，`RB = P*a/L`。
- 剪力：`V(x)=RA`，当 `0 <= x <= a`；`V(x)=RA-P`，当 `a < x <= L`。荷载点采用左极限。
- 弯矩：`M(x)=RA*x`，当 `0 <= x <= a`；`M(x)=RA*x-P*(x-a)`，当 `a < x <= L`。
- 挠度：令 `EI=E*I`。
  - `0 <= x <= a`：`v(x)=-P*b*x*(L²-b²-x²)/(6*L*EI)`。
  - `a < x <= L`：`v(x)=-P*a*(L-x)*(L²-a²-(L-x)²)/(6*L*EI)`。

最大弯矩在 `x=a`，为 `P*a*b/L`。最大挠度位置和数值由高密度采样数组中绝对值最大的点确定；采样时额外插入荷载位置 `a`，使最大弯矩位置精确。

## 校验与验收

1. 对 `L=1000`、`P=100`、`a=300`，验证 `RA=70 N`、`RB=30 N`。
2. 验证剪力在荷载点左右为 `70 N` 和 `-30 N`，弯矩在荷载点为 `21000 N·mm`。
3. 验证两端挠度为零，荷载点左右的挠度连续。
4. 验证 `a=500` 时计算结果与第一阶段跨中模块相同。
5. 验证 `a<=0`、`a>=L`、非数值和无穷大位置抛出 `ValueError`。
6. 验证结果可直接传给三个现有绘图函数。

本阶段不支持组合荷载、均布荷载、支座处荷载、塑性、剪切变形或动态效应。
