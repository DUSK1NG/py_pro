# 荷载—挠度 CSV 数据与曲线设计

## 目标

在现有简支梁理论计算、静态图片测量和误差对比基础上，增加多组荷载—挠度数据的 CSV 导入、理论计算、曲线绘制和误差导出功能。本阶段不开发视频、实时摄像头或在线数据抓取。

## 数据格式

CSV 必须包含以下两列：

- `load_n`：荷载，单位 N；
- `measured_deflection_mm`：实测跨中挠度，单位 mm，向下为负。

可选列：

- `theoretical_deflection_mm`：外部提供的理论值，用于核对，不覆盖程序按当前梁参数计算的理论值；
- `experiment_id`：实验编号；
- `repeat`：重复实验编号。

数据读取后按荷载升序排序。荷载必须是有限非负数，挠度必须是有限数；必须至少有两行数据，荷载不能重复，缺失列和空值给出明确中文错误。

## 计算与输出

程序使用当前理论计算结果的跨中理论挠度作为每组荷载的理论参考。输出字段包括：

- `load_n`；
- `measured_deflection_mm`；
- `theoretical_deflection_mm`；
- `error_mm = measured - theoretical`；
- `absolute_error_mm`；
- `relative_error_percent`。

理论值接近零时，相对误差输出为空，避免除零。汇总输出最大绝对误差、平均绝对误差和荷载—挠度曲线是否处于合理误差范围。

## Streamlit 界面

在图像测量/数据分析区域增加 CSV 上传控件。上传后显示：

1. 数据预览表；
2. 理论与实测荷载—挠度曲线；
3. 最大绝对误差、平均绝对误差和合理性提示；
4. 对比 CSV 下载按钮。

当前梁参数变化后，重新计算理论曲线；用户不上传 CSV 时不显示该区域的结果。

## 模块边界

- `utils/load_deflection.py`：CSV 解析、字段校验、理论值计算、误差统计；
- `vision/load_deflection_ui.py`：上传控件、表格、图表和下载按钮；
- `sample_data/load_deflection_example.csv`：仅供测试和演示的示例数据；
- `tests/test_load_deflection.py`：正常数据、排序、缺列、空值、重复荷载和零理论值测试。

## 真实性与版权边界

网上实验报告中的数据只能作为参考或演示，必须保留来源链接和数据性质说明。没有实验原始记录的数据不得用于项目最终实验结论。真实实验数据由用户后续上传并通过同一 CSV 格式导入。

## 验收标准

- 合法 CSV 能正确读取并按荷载排序；
- 非法列名、空值、重复荷载、负荷载和非数值数据给出明确错误；
- 已知理论数据与实测数据相同时误差为零；
- 理论值为零时不发生除零；
- 曲线图和对比 CSV 可生成；
- Streamlit 应用可编译和启动；
- 原有测试全部保持通过。
