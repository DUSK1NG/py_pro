# Streamlit 最小界面设计

## 目标

新增 `app.py`，将已完成的三类理论荷载计算、单位换算与图形绘制整合为单页 Streamlit 应用；不处理图片、视频或 OpenCV。

## 页面结构

侧边栏参数区包含荷载类型下拉框（跨中集中力、任意位置集中力、满跨均布荷载）、长度/力/均布荷载单位下拉框，以及对应数值输入。内部先调用 `utils.units` 转换为 mm、N、N/mm，再调用相应 `mechanics` 模块。

主区域提供“开始计算”按钮。成功时展示左右反力、最大剪力、最大弯矩、最大挠度及其位置，并显示 `visualization.plotting` 返回的剪力、弯矩和挠度 Figure。错误时使用中文 `st.error` 提示，不中断页面。

## 荷载规则

- 跨中集中力：隐藏荷载位置，内部设为 `L/2`。
- 任意位置集中力：显示位置 `a`，并以选择的长度单位输入；必须满足 `0<a<L`。
- 满跨均布荷载：显示 `q` 和均布荷载单位；不显示 `a`。

弹性模量 `E` 仅支持 MPa，惯性矩 `I` 仅支持 mm⁴，避免在首版引入更多转换选项。

## 验收

通过 `streamlit run app.py` 启动后，三个荷载类型均可计算并显示三张图；无效参数显示中文错误。新增 `streamlit` 依赖；不改动力学或图形公共接口。
